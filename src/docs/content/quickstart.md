# Quickstart

Set up a Holdr wallet on testnet and get test funds. It takes about five minutes and costs nothing.

## 1. Create a wallet

1. Open [holdr-wallet.vercel.app](https://holdr-wallet.vercel.app).
2. Tap **Create a new wallet**. Holdr shows a 12-word recovery phrase.
3. Write the 12 words down on paper, in order. Holdr asks for three of them to check.
4. Set an unlock password for this device.

> **Warning** Your recovery phrase is the only way to restore your wallet. Holdr never sees it and cannot recover it. Never type it into a website or send it to anyone, including Holdr.

## 2. Switch to testnet

Holdr starts on **Robinhood Chain testnet**. You can check or change the network in **Me → Network**. See [Testnet](/docs/testnet) for the details.

## 3. Get test ETH

ETH pays the network fee (gas) for every transaction. On testnet:

1. Copy your address from **Receive**.
2. Open the [Alchemy Robinhood testnet faucet](https://www.alchemy.com/faucets/robinhood-testnet) and paste it. You get 0.1 test ETH a day.

> **Note** The faucet asks that the address has a little ETH and some history on Ethereum mainnet. If your new wallet is not eligible, use a wallet that is, then send the test ETH to your Holdr address.

## 4. Get test USDG

The launchpad prices everything in USDG. On testnet, Holdr runs a free **Test USDG** (tUSDG) that anyone can mint, up to 100,000 per transaction. A button for it comes with the launchpad app; until then it is available on the [Test USDG contract](https://explorer.testnet.chain.robinhood.com/address/0xf820a6e153452B6699Ce9BD794C78E644284F033) (`faucet(amount)`, 6 decimals).
